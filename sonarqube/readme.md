# SonarQube

SonarQube provides static code analysis for quality and security checks.

- Website: https://www.sonarsource.com/products/sonarqube/
- Image: https://hub.docker.com/_/sonarqube

## Access

By default, SonarQube is exposed on `http://localhost:19000`.

## Notes

- The default image tag is `26.4.0.121862-community`.
- Data, extensions, and logs are persisted in named Docker volumes.
